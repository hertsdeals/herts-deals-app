# Herts Deals app

The store version of the Herts Deals app for iPhone and Android, built with Capacitor.

- `www/` – the app itself (same design as hertsdeals.co.uk/app). Data comes live from `https://hertsdeals.co.uk/wp-json/hd/v1/app`, with a bundled copy (`www/feed.json`) for first launch offline.
- `android/`, `ios/` – native projects generated by Capacitor.
- `assets/` – source icon and splash images (`npm run assets` regenerates all sizes).
- `codemagic.yaml` – cloud builds (no Mac needed).

App ID: `uk.co.hertsdeals.app`

## Builds
- **Android test build** – runs now, gives an APK to install on an Android phone.
- **Android release** – needs the upload key and a Google Play service account adding in Codemagic.
- **iPhone release** – needs the App Store Connect API key adding in Codemagic as the integration "Herts Deals".
